**最值得先做的 6 件事（按风险排序）**

1. **给上行请求体加大小上限**（`http/requests.ts`）——唯一能被单个请求直接打崩进程的问题。
2. **修协议 / 文档 schema 的约束漂移**并把它纳入契约测试（`protocol/messages.ts` ↔ `document/schema.ts`）——wire 上已经在收非法数据、也在拒合法数据。
3. **修 `/api/resources/index?kind=` 的空串 / 未知值处理**（现在 fs 实现抛 500、memory 实现返回空，注释与实现相反）。
4. **修心跳超时踢人后不广播 `editor_state`**（编辑器会一直显示「前端已连接」）。
5. **修编辑器「服务端重启后再点运行 → 前端拿到空场景」**（`lastPushedSceneText` 未清）。
6. **非法资源 ID 的写 / 删回 400 而不是 500**，与读路径的 404 口径统一。
